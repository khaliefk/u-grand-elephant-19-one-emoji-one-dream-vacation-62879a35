Entry for the [make.fun bounty "One Emoji, One Dream Vacation"](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35).

The task is simple. Send exactly one emoji, nothing else, standing in for the trip of your dreams. This program writes 🗻, Mount Fuji, to `entry.txt`. One character, four bytes, no newline, no words.

Why Fuji: a generic beach says any holiday, Fuji names one particular dream, the trip to Japan. It is a faraway place and a postcard in one glyph, a snow-capped peak a stranger recognises at a glance, and it reads clearly at small size on any screen.

Run it with `python3 main.py`. It writes to `/output/entry.txt`, or to `$OUTPUT_DIR/entry.txt` when that is set. It checks the entry is exactly one emoji code point before writing, then reads the file back to confirm it matches.
